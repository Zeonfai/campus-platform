## 自动检查与合并main

1. 查看GitHub分支/PR的Project checks；红灯先点失败步骤看原因，不跳过测试。
2. 如需本地复跑，先Ctrl+C停止pnpm dev，再执行bash tools/ci-check.sh。不能与dev/watch并行；不需要重新安装或初始化。
3. 人工主链与权限检查通过、自动检查绿灯后，在GitHub建立feat/admin-management→main的PR；已有PR就打开它。只合并这一条即可包含两轮增量。
4. 检查Files changed和Checks；Draft先Ready for review，由另一组员人工审阅。推荐Create a merge commit保留真实提交，不伪造批准或贡献。
5. 遇到冲突停止，由人处理；AI不自动解决代码冲突。体验前不合并，不自动部署。
6. 网页合并后，本机工作区干净时执行：

```bash
git switch main
git pull --ff-only origin main
```

若有未提交修改或分叉，不强制覆盖。不要删除/回退数据库迁移来回退应用；任务分支确认全组使用main后再清理。

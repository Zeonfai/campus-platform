# 本地 PostgreSQL 基础设施验证

日期：2026-10-15。使用项目固定摘要的 PostgreSQL 17 官方镜像。真实测试，不使用数据库 mock。

- 初始两个应用数据库的 public schema 均无表。
- 两服务 migrate deploy 和基础种子执行成功。
- 再次执行迁移及种子后，元数据、updatedAt 和成功迁移清单完全不变。
- core_app / workflow_app 可访问本库；访问对方数据库被 PostgreSQL 以 42501 拒绝。
- 两账号的错误密码均以 28P01 拒绝。
- 两账号均无 superuser、createdb、createrole、replication、bypassrls 权限。
- 初始迁移与种子仅含服务元数据，不代表预约、审批、维修或业务授权已完成。

# M2 前端交接

`ApplicationPage.vue` 对应 `/applications`，使用生成契约类型和 D 的内存会话访问公开 API。

当前页面提供整室申请、本人/审批范围分页和状态筛选、详情与审批记录、当前级审批、本人开始前撤回、手动刷新同步状态及审批流程只读展示。页面不调用内部资源接口，不持有服务凭据。

写入使用独立 UUID 幂等键；网络失败时保留相同内容的键供原操作重试。成功回执后重新读取当前申请，不以历史回执更新最终状态。`SYNCING`、`RELEASE_PENDING`、`SYNC_FAILED` 都不展示最终批准或释放成功。审批按当前快照 revision 提交；409 提示先刷新。会话失效或离开页面时清理页面数据。不要把刷新浏览器作为未知结果下的立即重新提交方式，应先查看已有申请。

前端按钮仅提供交互提示。用户公开上下文只有 permissions，不含角色和管理范围；是否处于当前审批角色、是否本人、是否已审批、院系/教室范围及状态合法性均由后端最终校验。政策管理写页面尚未提供。

阅读根规则、apps/workflow/src/modules/m2/AGENTS.md 及接口契约。业务 DTO 从 @campus/contracts/api 导入，禁止复制另一套手写类型。构建和类型检查通过不等于已经完成浏览器人工验收，真实后端/数据库链路由整体集成验证确认。
